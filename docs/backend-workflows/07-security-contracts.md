# BACKEND-601 — Seguridad y contratos

Parte de `main`. Crea suite reproducible sin infraestructura externa para JWT ausente/inválido/expirado, rol insuficiente y errores 400/401/403/409 mediante factories/fakes. No implementes dominio ni bloquees por endpoints no existentes: usa hosts de prueba mínimos.
